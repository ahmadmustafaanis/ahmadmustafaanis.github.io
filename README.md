# ahmadmustafaanis.github.io

Personal site of Ahmad Mustafa Anis, built with Jekyll and served by GitHub Pages.

- `index.html`, `story.html`, `blog/` are the pages; `_layouts/` and `_includes/` hold the shared shell.
- `assets/css/site.css` is the design system (colour, type and layout tokens are at the top).
- `assets/js/patch-field.js` draws the homepage portrait figure in WebGL. Its data
  (`assets/data/patch-field.json`, `images/portrait.webp`) is generated by
  `tools/build_patch_field.py`; rerun it after changing the portrait or the backbone.
- `assets/js/globe.js` draws the globe on the Story page.
- `BLOGGING.md` explains how to add a post.
